# One-click scans (no AI, no tokens)

Right-click in the Explorer:

- a **folder** → *Terraform: Scan Folder*, *Kubernetes: Review Manifests*, *Terraform: Cost*, *Diagram: Spec from Terraform*
- a **Dockerfile** → *Docker: Audit Dockerfile*, *Docker: Build → Run → Diagnose*

Findings land in the **Problems** panel with rule IDs (e.g. `TF-SEC-003`) and severities. Everything is also in the **InfraCortex** sidebar and the Command Palette.
