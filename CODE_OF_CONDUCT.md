# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability, marked "Code of Conduct"), or by contacting a maintainer directly. Reports are handled confidentially.
